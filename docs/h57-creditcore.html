The evidence chain

  1. Two-view co-training (required method): 83 scale-free features split into View A (potential field & subsurface, 51) and View B (surface, 32); 512-px spatial blocks with a 300 m buffer, 5 folds. Per-view OOF AUC A 0.6011 / B 0.7223 / joint 0.7295.
  2. The required independence test fired against us: Spearman 0.637 against the pre-registered 0.6 → ABANDON, and the joint arm lost to View B on the deciding instrument (0.0236 < 0.0244). No co-trained configuration was promoted and the pseudo-labelling stage was never run for emission (IR-57-101).
  3. What did survive is exact: thirteen owner-reported scores are fitted exactly at |G| = 14,088.7 px, the pair h33-2-b2 ⊂ d2-8 implies the same credit (5,223.13) so the 6,436 cells d2-8 adds earn exactly zero, and the shared support of the five top files is the 25,517-cell core.
  4. But the allocation is not identified: 574 coverage patterns against 13 equations give an interval, and the "consensus ⇒ at-least-as-much credit" refinement is infeasible against the reported scores (IR-57-102). Hence the bracket.
  5. Emission: metric-aware dotted placement (every pair ≥3 px apart, ≥200 m from the catalogue, inside the footprint, 0 cells on the catalogue), then the gates re-read from the bytes. Deterministic: three rebuilds produced the same sha256.

What would change the verdict

  • An organizer-side truth set showing the credited core is not where the hidden truth is.
  • A re-inversion whose LP lower bound falls below the standing best after a new public score reports.
  • A held-out instrument showing the novel arm's enrichment (9.24 % vs 1.58 % control within 3 px of the catalogue) collapsing to the control rate.
