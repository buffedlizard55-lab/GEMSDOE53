Run card (summary; full JSON in evidence/run_card.json)

HypothesisDistance-to-known-faults features built from the training labels leak the target (a deterministic label function). Recomputing them with learn-predict separation and scoring with whole-segment hide-and-recover removes the inflation without losing the legitimate spatial signal.
MechanismFeature = log1p(min(distance to known-fault pixels, 60)). Built from the same labels it is trained on, it is exactly 0 on every positive (Exp 1: 60,988/60,988) and >= 0.6931 (distance >= 1 px) on background, so separability is 1.0.
Named non-fault process that could mimic itMapping bias: the catalogue traces faults that were already mapped, so proximity to a mapped trace reflects where mappers worked (survey density, road access, outcrop), not where faults are. This is a non-fault process that the holdout cannot separate from fault signal.
Holdout (HOLDOUT-DTI)pooled 0.0352, 95% CI [0.02817, 0.042229]; 60,988 withheld fault px; evaluator gems53.core.dti 1.0.0

The highest rank correlation in the registry is 0.517 (12GEMSDOE multiphysics_submission, 97.2% dot overlap). Both are below the 0.90 correlation flag but well above the value-similarity level of a unique file. Holdout proxy 0.0352 (HOLDOUT-DTI) is not an organizer score.
