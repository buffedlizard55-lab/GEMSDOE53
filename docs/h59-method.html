H59 · Geological hypothesis and algorithm

Multi-scale geophysical edge
coherence + co-training disagreement.

The discovery signal is disagreement between a geophysical view (subsurface) and a surface view. Where the geophysical view sees strong edges but the surface view does not, the fault may be buried beneath cover — the exact class missing from the USGS/INGENIOUS catalogue.

The geological hypothesis

The northwestern Great Basin has numerous faults that are detectable in potential-field geophysics (gravity, magnetics) but invisible at the surface because they are buried beneath alluvial fill, basin sediments, or volcanic cover. These buried faults are systematically underrepresented in the USGS Quaternary fault catalogue and the INGENIOUS field mapping.

By detecting disagreement between a subsurface view (View A) and a surface view (View B), we can specifically target these buried structures:

  • A-confident, B-abstains: Buried fault beneath cover → high-value candidate for new discovery
  • B-confident, A-abstains: Surface artifact (road, erosion, canal) → suppress
  • Both confident: Likely already catalogued → lower priority

Co-training disagreement (Blum & Mitchell, 1998)

Following Blum & Mitchell (COLT '98), we test the conditional-independence assumption empirically:

  • View A and View B each produce a per-pixel edge score, rank-normalized to [0,1]
  • A-only = pixels where View A > 75th percentile AND View B < 40th percentile
  • B-only = pixels where View B > 75th percentile AND View A < 40th percentile
  • Measured: 532,408 A-only pixels (buried fault candidates)

The independence assumption is tested by correlating spatial-block out-of-fold errors. In this implementation, the A-only boost enters the ranking field as an additive term weighted at 20%.

Fault-tip structural continuation

Geological principle: faults propagate laterally over geologic time. The most likely location for an uncatalogued fault segment is at the tip of an existing mapped fault, in the along-strike direction.

We identify fault tips as catalogue pixels with ≤2 8-connected catalogue neighbors (55,045 tips identified). The ranking field receives a boost proportional to exp(−d/2000m), where d is distance to the nearest tip. This creates a 2km "continuation halo" around each tip.

Ranking field composition

The final ranking field is a weighted combination:

ranking = 0.35 × geophysical_edges     (multi-scale gravity + magnetic edges)
        + 0.15 × surface_score         (radiometric + slope + conductivity)
        + 0.15 × tip_proximity         (exp decay from fault tips)
        + 0.15 × external_score        (LiDAR scarp + GeoDAWN extensions)
        + 0.20 × A_only_indicator      (co-training disagreement)

A near-catalogue penalty smoothly zeros ranking within 300m of any catalogue pixel. The result is then restricted to pixels ≥200m from the catalogue (the exclusion ring) and rank-normalized.

Metric-aware greedy placement

The emission step uses the repo's greedy_emit function, which maximizes expected kernel coverage under the DTI metric's triangular kernel k(d) = max(1 − d/300m, 0). Given a fixed budget of 37,654 pixels (same as H33's 0.2778), the greedy algorithm places pixels where the ranking field is highest while accounting for overlap with previously placed pixels.

The full pipeline is in scripts/build_h59_submission.py. To reproduce:

# 1. Restore competition data (requires access to sibling repos)
python3 scripts/restore_data.py --force

# 2. Build the submission
PYTHONPATH=src python3 scripts/build_h59_submission.py
