## Preregistered test for H55-PROFILE

1. Use spatial whole-component quadrant folds and the existing 80-pixel buffer; keep the same eligible footprint, proxy-negative definition, random seed, learner, prior adjustment, metric kernel, global-equivalent emitted density, and placement procedure as R2. Hold out complete 8-connected catalogue components. Proxy negatives mean “not in the catalogue”, not geological absence.
2. Compare at identical per-fold budgets: View B baseline, existing structural-contrast baseline, and H55-PROFILE. Report every fold, DTI, paired differences, plus spatial ROC only as a secondary diagnostic. Candidate-vs-baseline must be based on fold DTI, not AUC.
3. Promotion criteria are frozen: candidate mean lift ≥0.005 over the strongest comparable baseline, improvement in at least 3/4 folds, leakage checks pass, and output format/uniqueness gates pass. Because the repository documents that its historical holdout has weak/negative correspondence with the public board, passing this proxy gate still does **not** establish an organizer score or justify a claim of beating 0.3195. No weekly slot is spent here.
4. If it fails, retain a research-only TIFF only if useful for reproducibility, mark it **not approved for upload**, record the negative result and do not select a weaker alternative post hoc. If feature support, folds, or score calculations are invalid, stop without writing a TIFF.

## Result / status — run completed 2026-10-07

H55-PROFILE was implemented across the **five preregistered offsets** (100, 200, 300, 400 and 600 m) without adding external data, tested on all four registered spatial folds, and **failed the slot gate**. Mean primary DTI was 0.196971 against the strongest comparable baseline, `view_B` at 0.194671: paired mean lift **+0.002300**, positive folds **3/4**. The fold-support condition passed; the required ≥+0.005 mean lift failed. Primary fold DTI was 0.158241, 0.274219, 0.140282, 0.215144; profile-augmented View B scored 0.178548, 0.271504, 0.136184, 0.189149. `view_B_h55` averaged 0.193846, below the original surface-only baseline. No candidate met all promotion criteria; no weekly slot was used.

The H55 binary GeoTIFF was generated **after** the holdout run as a research artifact only: local format gate passed; 25 accessible aligned prior TIFFs were compared; decoded-pattern uniqueness, 20% union-support novelty and non-union tests passed in that bounded inventory. The file was independently reopened and has finite [0,1] values, correct single-band template geometry and an internal footprint mask. This is not a claim of global uniqueness, hidden-label skill, competition approval, upload acceptance or score above 0.3195. The static site clearly marks it “NOT approved for upload”; `submission/LATEST.txt` and `submission/R2_LATEST.txt` were not changed by this candidate. See `evidence/h55_holdout.json`, `evidence/submission_h55.json`, `evidence/uniqueness_h55.json` and `docs/h55.html`.

H55-JUNCTION and H55-STRAIN remain untested. H55-SEISMIC remains deferred: official USGS ComCat FDSN documentation was reviewed, but a direct request from this sandbox failed TLS/connection before returning data bytes. No external seismic data influenced this file.
