1 How it stays current without a human

  1. scripts/refresh_feed.py copies every evidence/*.json verbatim, writes submission.json from the newest gate report, publishes the raster and the per-candidate reasoning CSV into docs/downloads/, and with --fetch re-scrapes the public leaderboard, recording status, fetched_utc and the row count parsed.
  2. .github/workflows/feed.yml runs it nightly and on push, then commits the JSON.
  3. The pages fetch() those files with cache: no-store and print how long ago each source is.

3 What is deliberately not in the feed

Any file-to-score mapping, including the group's own 0.2778. The public board is participant-level and publishes no filename, hash or upload receipt, so "this file scored that" cannot be verified from an official source. Such statements are labelled owner-reported wherever they appear — see Irregularities.
